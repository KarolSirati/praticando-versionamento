# Praticando Versionamento

Repositório criado para praticar e fixar alguns conhecimentos em **Git e GitHub**.

## Objetivo

Aprender na prática o fluxo de versionamento de código, do início ao fim, explorando novas possibilidades, conhecendo novos comandos e atalhos e entendendo como estruturar um projeto do piso ao teto.

## O que vou praticar

- Git e GitHub
- Commits
- Branches
- Merge
- Resolução de conflitos
- Push, pull e fetch
